# Slope Fields in Python

`plt.quiver(X, Y, U, V, angles='xy', pivot='mid', headlength=0)`
* `X, Y`: grid coordinates (where ticks go)
* `U, V`: vector components (direction/slope)
* `angles='xy'`: matches angles to coordinate axes (not screen pixels)
* `pivot='mid'`: centers ticks on coordinates
* `headlength=0`: removes arrowheads to make plain ticks
