# Repository Rules

## Formatting Guidelines
- **No LaTeX Formatting:** Never use LaTeX math delimiters (e.g., `$ ... $`, `$$ ... $$`) or LaTeX commands (e.g., `\mu`, `\frac`, `\le`, `\ge`, `\times`).
- **Use Markdown & Unicode:** Always format mathematical expressions, statistical notation, and equations using standard GitHub-flavored Markdown, code spans, and Unicode characters:
  - Symbols: `μ` (mean), `x̄` (sample mean), `σ` (pop sd), `s` (sample sd), `SE` (standard error), `≤`, `≥`, `±`, `≈`, `*`.
  - Equations and fractions: Use standard text/code formatting, e.g., `(bs_mean - mu) / (bs_sd / sqrt(n))` or `x̄ - u * SE`.
